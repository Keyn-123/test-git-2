1. git status — проверка статуса всего проекта
2. git add . или [files] — подготовка файлов к сахранению
3. git commit -m "comment" — оставить коментарий и сахранить фаил на лакальный
4. git log или git log --oneline — посмотреть коментарий и что его оставил
5. git push [rep_link] [branch_name] — Сахранить данные на репазиторий github
6. git push origin master
7. git remote -v — узнать ссылку на репазиторий
8. git branch — узнать название ветки
9. git reset — удаляет файл из промежуточной зоны сохранения
10. git diff — проверка какие канкретно строки изменилась в этом файле проекта
11. git reset --hard — удалит и вастоновит все файлы до последней точки сахранения в рипозиторий Github
